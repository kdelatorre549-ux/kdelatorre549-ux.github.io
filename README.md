# Karen De La Torre | Personal Website

**Live site:** [https://kdelatorre549-ux.github.io](https://kdelatorre549-ux.github.io)

## About This Project

This repository holds my personal "About Me" website, built for my Texas Tech University coursework. The site introduces me to instructors, classmates, and future employers as a Computer Science student and app developer. It covers my goals for the course and my career, my hobbies and interests, and a link to my GitHub profile. The page started as a local HTML file, gained an external stylesheet, and is now version-controlled with Git and published with GitHub Pages.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure and content, written in semantic HTML (`header`, `main`, `section`, `footer`) |
| `style.css` | All visual styling: colors, fonts, spacing, and layout |
| `README.md` | This guide to the project |

## Design

The color palette comes from the Google Arts & Culture Art Palette tool:

- `#814c58` plum (header and links)
- `#965b49` terracotta (section headings)
- `#a5767d` dusty rose (list bullets)
- `#c497a0` soft mauve (footer and heading underlines)
- `#e6c2ce` blush pink (page background)

Headings use Trebuchet MS and body text uses Georgia for easy reading.

## Built With

- HTML5 and CSS3
